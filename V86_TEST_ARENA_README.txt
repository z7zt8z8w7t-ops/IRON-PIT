Splash → TEST ARENA → select a currently playable arena → workshop with all equipment unlocked → START ARENA TEST.

The workshop starts empty so you can choose any chassis, compatible weapons, pilot and livery. Test matches face one AI opponent. ARENA SELECT in the battle HUD lets you return immediately and change arenas. Workshop BACK returns to the test selector; selector BACK returns to splash.

Testing does not grant wins, rewards or campaign progression. Normal equipment settings, arena preference and unlock preference are restored on exit.

This patch exposes the SIX arena modes already implemented in v85: Dust Crucible, Drowned Sector, Blackout, Rotor Pit, Frostbite and Chainworks. The nine rebuilt arena designs, shared stadium and new hazards still need gameplay integration. The selector is generated from the arena registry, so additional playable arenas appear automatically.
